# Satisfaction-Expectations_Pediatric-Primary-Care_Parent-Survey

This GitHub repository shares the analysis code used for the manuscript "Parental satisfaction and expectations in pediatric primary care: a nationwide survey of parents".

# Analysis scripts

data-analysis.qmd was used for the data analysis of this manuscript. Data cleaning scripts were run prior to the analysis script, but contain individual level data output. Hence, the cleaning scripts are not shared here on GitHub. The data analysis script of the manuscript [Primary Care for Children in Switzerland: a nationwide parent survey](https://github.com/LorenzLeuenberger/Primary-Care-for-Children-in-Switzerland_Parent-Survey) was used to prepare data for this second manuscript.
